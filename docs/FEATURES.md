# Feature Contract

## First release

- public guestbook
- name + message
- Cloudflare Turnstile
- one signed entry per 24 hours per visitor fingerprint
- short-window submission limiting
- cursor pagination
- visible/hidden/deleted moderation states
- responsive book layout
- graceful loading/error states

## Explicit non-goals

- accounts
- Discord OAuth
- image uploads
- Markdown/rich text
- AI moderation
- WebSockets
- complex analytics

Final Fantasy XIV is an interaction-model reference only. The Honk Tavern implementation uses original branding, layout, artwork and code.
